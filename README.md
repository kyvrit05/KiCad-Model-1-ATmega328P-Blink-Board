# KiCad---Model-1-ATmega328P-Blink-Board

As part of strengthening my fundamentals in PCB design and modelling, I started with a simple introductory project: designing a PCB that allows an LED to blink.

The project focuses on understanding the basic PCB design workflow, including schematic creation, component selection, circuit layout, routing, and preparing the board for fabrication. Although the circuit itself is simple, it provides a practical foundation for developing essential PCB design skills and understanding how electronic components are translated from a schematic into a physical PCB.

Key Notes: 

1) Shortcuts: 
A - bring up circuit components 
P - power and GND components 
V - input a value to a component 
R - rotate a component by 90'

2) Abbreviations:
ERC - electrical rules checker
THT - through-hole ( for soldering back of the PCB )
SMD - surface-mount ( no holes on PCB )
ESR - equivalent series resistance ( how much internal resistance there is in a component )
